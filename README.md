## Uji Kompetensi Fullstack

### Getting Started

#### Backend
One-time set up:

* Install composer for your OS
* Go to backend directory
* Run `composer install`
* Set up local `.env` file (copy and edit from .env.example)

Running development server:

* Run `php artisan serve`
* development server listens at http://localhost:8000

#### Frontend
One-time set up:

* Go to frontend directory
* Run `npm install`

Running development server:
* Run `npm run dev`
* development server listens at http://localhost:5173
